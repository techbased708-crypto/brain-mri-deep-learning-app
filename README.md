# 🧠 Brain Tumor MRI Classification App

A deep learning-powered web application built with **Streamlit** and **EfficientNetB2** to classify brain tumor types from MRI scans.

## 🚀 Live Demo
[Click here to view the live app!](YOUR_STREAMLIT_URL_HERE) *(Deploy karne ke baad yahan apna Streamlit link dal dijiyega)*

---

## 📌 Features
- **Deep Learning Model**: Uses **EfficientNetB2** architecture pre-trained and fine-tuned for high accuracy.
- **Tumor Categories**: Classifies MRI scans into 4 categories:
  - Glioma Tumor
  - Meningioma Tumor
  - Pituitary Tumor
  - No Tumor
- **Interactive UI**: Built using Streamlit for a fast, clean, and user-friendly web interface.
- **Git LFS Integration**: Efficiently handles large deep learning model weights (~40MB).

---

## 🛠️ Tech Stack & Libraries
- **Python** (Programming Language)
- **TensorFlow / Keras** (Deep Learning Framework)
- **Streamlit** (Web App Framework)
- **NumPy & Pillow** (Image Processing)
